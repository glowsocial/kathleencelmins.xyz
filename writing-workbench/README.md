# Voice Writing Workbench

This folder is private working material. Published pieces belong in `content/writing/`, but nothing moves there until Kathleen explicitly says it is ready to publish.

## Folder Flow

- `inbox/voice-inbox.md`: raw dictated notes and first captures.
- `drafts/`: rough pieces that have a possible shape but are not public.
- `fragments/`: stray lines, images, turns of phrase, memories, or ideas.
- `archive/`: finished private pieces or old workbench material worth keeping.

The subfolders are ignored by git except for `.gitkeep` placeholders. That keeps raw notes and messy drafts out of commits and deploys.

## Dictation Frame

Use this when capturing a fresh note:

```text
Topic:
What happened?
What I noticed:
Why it matters:
The line I want to remember:
Possible title:
```

## Cleanup Standard

When cleaning a dictated note:

- Preserve the sentence shapes and phrases that sound like Kathleen.
- Cut repetition, filler, throat-clearing, and repeated setup.
- Keep specificity, edge, humor, uncertainty, and contradiction.
- Do not sand it down into corporate, generic, motivational, or over-polished prose.
- Find the point of the piece before deciding whether it should become an essay, short post, fragment, private journal entry, or title seed.
- Keep publishing separate from cleaning. A cleaned draft stays in the workbench unless Kathleen says it is ready for `content/writing/`.

## Suggested Output

For a dictated note, return:

1. Cleaned draft
2. What this seems to be about
3. Lines worth keeping
4. What it could become

If there are multiple possible directions, name them instead of forcing the note into one shape too early.
