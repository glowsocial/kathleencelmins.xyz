# Fonts for the link-preview cards

`lib/og.js` draws the share cards with these, so a build never has to reach Google Fonts.
They are the site's own three typefaces, as WOFF files from Fontsource (latin subset).
All three are under the SIL Open Font License 1.1: Ms Madi (Robert Leuschke), Source Serif 4 (Adobe), Inter (Rasmus Andersson).
